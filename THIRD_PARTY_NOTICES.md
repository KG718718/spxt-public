# Third-party notices

The K-SESSION project code is licensed under the root [MIT LICENSE](LICENSE).
Third-party dependencies remain subject to their own original license,
copyright and NOTICE files. The project license does not replace those terms.

The hosted build collects original license and notice files from the exact
installed dependency versions into a cloud-only license report. That report
contains an inventory with version, source and SHA-256 hashes and preserves
third-party attribution without company-data redaction.

The current online installer contains the reviewed application source, scripts,
root LICENSE and this notice, listed in PACKAGE-MANIFEST.json. It does not bundle
Node.js, npm dependency binaries, Python, OCR engines or model binaries.
The installer obtains pinned Node.js and dependencies from their official sources,
keeps the downloaded Node LICENSE and installed dependency notices, and checks
integrity. Online installation does not waive third-party license obligations.

The generated hosted dependency license report is separate verification evidence,
not a runtime component or release approval. Any future package that redistributes
third-party components must include their applicable original license/NOTICE files
and complete the corresponding distribution review before shipping.

Native binary components (including graphics libraries), bundled Node.js,
optional OCR/Python/models and any browser libraries, fonts or icons require
their own distribution review. Components absent from a package must not be
claimed as bundled. See [licensing status](https://github.com/KG718718/spxt-public/blob/codex/public-v1/docs/licenses-and-distribution.md).

No company business records, accounts, attachments or credentials belong in
these notices or in the zero-data installation package.
