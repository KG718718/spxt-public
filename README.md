# K⁺-SESSION

项目审批、付款申请、欠款台账、发票核对、奖金/月结、统计导出与备份恢复系统的独立公开版。

**准备中：候选分支已有部分核心源码，但尚无完整运行服务或可用安装包，不能独立启动系统。**

[查看候选源码与审查记录](https://github.com/KG718718/spxt-public/tree/codex/public-v1)：现有基础、服务费/奖金、月结、启动安全、欠款、邮件、备份与导出模块，托管 Windows 已通过310项检查（含实际文件系统及XLSX）。没有预置账号、业务数据或公司参数；合成测试不进入未来安装包。完整服务端、Admin配置与页面、HTTP和安装封装仍未完成。

## 方向

- 生产安装包零业务数据：不带供应商、收款对象、客户、员工、项目、付款、欠款、发票、奖金/月结记录或附件；不提供改名后的旧数据或自动导入的演示数据。
- 不预置任何登录账号。安装者先创建首个管理员，再自行建立自己的员工、供应商、收款对象及关联。
- 保留程序功能和基础字段/类型；零数据仅指新安装，不会在升级或重启时清空已有数据。
- 不包含公司凭据、内部文档、配置、备份或私有提交历史；合成测试数据与生产安装包隔离。
- 逐文件审查后引入公共源码；去掉原公司名称和Logo，品牌使用K⁺-SESSION。
- 已确认：Admin配置使用者自己的发票购买方全称；未配置或名称不匹配时不能提交发票，保留服务端校验。
- 开发记录、测试和发行物在GitHub保存，不在开发机另存公开版副本。
- 已确认：品牌显示为 **K⁺-SESSION**，加号位于K的右上方；首次安装由使用者创建管理员，不提供公司账号或共享默认密码；OCR作为可选组件。
- 上述为已确认需求，尚非已实现能力。员工替票改为Admin配置已获有条件确认，要求其他现有规则不变；首版Windows已确认，真实局域网部署方案与双机验收仍待确认；不承诺公网、多租户、跨平台或完全离线。
- 已确认取消原公司专属收款机制，不指定替代对象、不新增替代配置，不把原特例转授所有公司收款对象；普通供应商与员工收款功能保留。此项尚未实现。
- 已确认服务费率、奖金档位及相关业务参数不内置公司数值，由Admin在页面配置；未配置不能暗中套值计算，历史快照不随参数变更被覆盖。当前服务费及奖金核心完成，完整界面、HTTP与跨模块验收待完成。
- 仓库地址暂不改名；公开产品名称不等于取消发票购买方校验。
- 项目代码采用 [MIT 许可证](LICENSE)，第三方组件遵循各自原始许可。
