# SPXT Public

项目审批、付款申请、欠款台账、发票核对、奖金/月结、统计导出与备份恢复系统的独立公开版。

**准备中：当前仅有规划文档，尚未提供运行代码或可用发行包。**

## 方向

- 不包含任何公司真实数据、账号、附件、凭据、内部文档或私有提交历史。
- 逐文件审查后引入公共源码；安装者配置自己的单位与管理员。
- 开发记录、测试和发行物在GitHub保存，不在开发机另存公开版副本。
- 首版Windows、首次初始化、配置及封装方案待确认；不承诺公网、多租户、跨平台或完全离线。
- 许可证尚待选择，本仓库当前不声明软件已经完成开源授权。
