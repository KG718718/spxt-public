# 完整公开运行时接入检查（候选，尚待云端测试）

范围：沿用原 Node 原生 HTTP 服务与既有审批、付款、欠款、发票、奖金、月结、导出及备份结构；不是新建简化系统。当前只有服务端接入，四个业务页面与封装包仍待完成。

失败证据：只读来源含固定购买方、固定替票名单、远程命令执行处理器、配置双写路由及缺税率默认计算。本轮定向前置断言五项失败；公开适配删除或替换这些未经公开配置的行为。不发布原来源文件或私有历史。

接入：
- 首次安装组件接入真实服务，启动前验证业务、系统配置及邮件配置。数据缺失但存在附件、备份、邮件配置或密钥文件时拒绝初始化。
- 配置存储对象是唯一当前参数来源；参数读取返回独立值，不复制审计全集。配置版本与审计同文件原子保存，业务 data 文件不为配置审计另写一次。
- 无税率默认值；明确保存的历史税额/税率原样读取，历史缺少两者不按当前税率猜算。缺奖金配置不使用公司分档。
- 员工替票由 Admin 在原账号生命周期事务中明确授权/撤销，带版本、原因及前后值审计，撤销全部旧会话；新账号默认未授权。现行授权不用于重分类历史收款类型或余票池。
- 欠款真实成本仅正式授权供应商；不将已取消的专属公司账号特例转授给其他收款对象。
- 删除远程命令执行/机器状态处理器；默认仅绑定本机回环地址，跨来源请求拒绝。
- 会话继续 PBKDF2、新随机 Token、HttpOnly/Strict cookie 与重启失效。畸形 Cookie 不抛异常；损坏的 PBKDF2 迭代参数不执行无界运算。
- 保存只清理由本次创建的临时文件；未知历史根字段保留。缺少旧编号计数仅在内存按已存编号最大值补读；明确计数与已存编号冲突则拒绝启动，不重置编号或改写旧数据。

公开审查：运行时代码无单位名称、真实员工名单、单位网络地址、实际记录、配置、凭据、媒体或旧 logo；仅保留通用规则文本、业务费用类别和发票内容校验词。动态邮件/文件访问仍受管理员配置及原权限约束，测试关闭真实投递。源文件只读，本次适配仅在内存与独立公开候选分支。

验收尚未完成：新增 hosted-only 完整服务 HTTP 测试覆盖零数据、真实登录、配置、授权与会话、全模块空态、重启、历史资料残留与损坏拒绝。云端通过前不称可安装。后续继续完整页面、业务闭环、截图和候选包门禁，不把此子批次当作任务完成。
