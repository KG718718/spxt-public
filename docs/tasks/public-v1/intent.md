# Intent｜K⁺-SESSION 公开版 V1

状态：意图已获用户确认；规格未冻结。

## 目标

从已验收的内部系统形成独立、无公司信息、可安装使用的公开版本，提供文档、合成演示数据和可验证发行包。

## 已确认边界

- 创建独立公开GitHub仓库，不改变原私有仓库的可见性。
- 直接在新仓库操作，不在本机建立或保存公开版副本、源码包或发行包。
- 处理脱敏、公开化更新和封装；不修改公司正式系统和业务数据。
- 不携带原始提交历史；文件进入公开仓库前完成审查。
- 2026-09-10补充：封装后的产品名称为K⁺-SESSION（加号在K右上）；去除原公司名称、Logo和真实信息。
- 购买方由Admin配置使用者自己的单位全称；未配置或名称不匹配时不允许提交发票，不以去除公司品牌为由删除校验。
- 首次安装由使用者自行创建管理员；OCR可选。具体安全、安装和未配置处理仍按Spec确认，不据此跳过Plan审批。

## 不在本轮范围

自媒体内容、公司系统迁移、新业务规则、公网SaaS、多租户、跨平台支持承诺、真实业务邮件、付费云服务。

## 成功标准

新用户无需任何公司账号、公司配置或开发机文件即可完成受支持的安装和首次登录；模块联动可用；源码、测试、文档、CI日志和发行包均不含公司资料，结果有证据。
