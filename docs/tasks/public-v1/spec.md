# Spec｜公开版 V1（待确认）

## 已核对的来源事实

以下是既有代码审阅事实的非敏感摘要，不复制任何内部值。

| 事实 | 公开版影响 | 建议处理（待确认） |
|---|---|---|
| 购买方校验和部分替票授权使用单位专用常量 | 清空数据后仍会套用原单位身份 | 改为安装配置，服务端仍为唯一校验权威；未配置明确阻止相关提交 |
| 空数据不含用户，新增用户要求先有Admin登录 | 新安装者无法创建第一个Admin | 一次性、本机执行的管理员初始化；初始化后关闭入口，不提供默认共享密码 |
| 奖金计算有公司历史算例回退 | 删除data文件仍不能消除真实业务及隐含公司分支 | 移除公开版中的公司历史回退，按明确配置计算；缺失配置提示而非伪造金额 |
| 邮件秘密存储依赖Windows DPAPI，OCR默认使用Windows Python路径 | 不能直接承诺Linux/macOS/Docker即装即用 | V1先支持Windows；OCR为可选独立组件，每位安装者自行配置邮箱 |
| 默认监听、登录请求控制等未按公开互联网部署验证 | 公开源代码不等于已具备公网安全条件 | V1以本机/受控内网为边界，默认本机绑定；公网部署另立安全规格 |
| 尚未确认独立许可证 | 可见仓库不等于明确的开源分发授权 | 代码/素材权利及许可证在正式代码发布前确认 |

## 不变的系统契约

权限、审批状态、费用/服务费公式、发票占用、奖金/月结冻结、历史证据、导出和备份恢复规则保持原验证原则。公司配置变化不得通过删服务端门禁、关闭审计或减少回归覆盖实现。

## 数据与文件边界

允许：逐文件审查后的运行代码、必要合成测试、新编公共文档、无秘密示例配置和打包流程。
禁止：真实data、附件、账号、凭据、生产配置、公司算例、内部日志/工具/路径、原截图/文档/历史提交。
公司默认税费和奖金档位不擅自当作面向所有用户的普适制度；具体默认值在实现前确认。

## 未配置与损坏数据

建议区分“首次没有数据”和“已有数据损坏”：后者拒绝启动并保留原件，不能当作首次初始化覆盖。此为待实现安全规格，不宣称当前已验证。

## 首版封装建议

Windows下载包提供明确启动、数据目录、升级、备份恢复和卸载边界；新安装不预置真实或共享默认账号。OCR联网安装、外部资源和SMTP配置必须如实说明，不宣称完全离线或免所有依赖。
