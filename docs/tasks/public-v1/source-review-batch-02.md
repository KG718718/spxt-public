用户确认公开版服务费与奖金参数不预置公司的数值，全部在Admin配置页面可见并维护。具体规格与执行子计划已先提交本仓库。本批实现其中服务费核心；奖金、页面、HTTP、审计和快照联动尚未实现。

- 在内存将同一49项测试先用于只读来源模块：14项符合新契约，35项失败。核心反例是空配置仍生成公司数值、缺配置仍可取得费率；部分失败来自新增错误码等契约差异，不表示来源系统有35个独立缺陷。
- 公开适配后同组49/49通过，覆盖空/部分配置、必填项、明确0、范围、空串/null/布尔/字符串数值、未知字段、原型继承和输入不变。
- 两文件完整阅读、语法检查及已知公司/内部地址路径/凭据定向标记检查通过。模式检查不是所有未来源码或完整发行包的秘密扫描证明。
- 测试运行于受限内存加载器，只允许本模块和Node内置assert，不写文件、不启动业务服务、不读取数据或真实账号、不发邮件。原始来源数值与失败输出未复制进公开仓库。
