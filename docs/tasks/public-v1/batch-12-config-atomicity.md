## 实现与数据契约

新增 public-config-store.js / public-config-http.js，public-startup.js 复用严格参数/审计校验。
允许业务字段继续是 taxRate、serviceFeeRates、bonusRules、invoiceBuyerName。单个参数组未提供则保持原状态；明确提交时完整校验，不含默认6%或公司档位。未知旧根字段保存原值但不进入 API 或审计，新请求不可写入未知字段或公式。

configVersion 与完整 configAuditRecords 保存在同一个 config.json 内；旧配置缺两字段时只读按版本0，首次成功保存才生成审计，不初始化迁移。审计按版本递增，记录id/time/user/action/changedFields/before/after；不作500条截断、不写入第二个 data.json。原 /api/logs 将其投影为 time/user/action/detail 并保留旧日志，只有 Admin 可读。财务业务数据与历史快照不被此组件写入。

同目录 wx 临时文件、fsync、字节核对、原子替换；内存只在替换成功后更新，没有第二次审计回调可将成功变成失败。保存前故障保持旧配置与内存；只清理自己成功建立的临时文件，名称碰撞不删除其他文件。保存前发现文件外部变更拒绝覆盖。

HTTP保持 /api/config GET/PUT 与 /api/logs GET；Admin 开始与收完请求两次实时权限核验，同源浏览器写入、JSON、64KiB请求上限及超时；员工配置只读允许字段。expectedVersion 必须合法，旧版本409。网络断开不等于服务端一定没保存，应刷新核对当前版本，不能自动重复或回滚。

## 验收与已知边界

内存专项包含显式0、非法/缺参数、权限、版本、未知字段、审计/响应副本不可变、501条保留、各阶段失败、外部变动、损坏/链接拒绝和重载。
云端合成 HTTP 专项覆盖权限、原方法契约、请求中撤权、并发单成功、真实磁盘故障、原业务文件逐字节保留、独立子进程重启和损坏审计拒绝；认证适配器是明确虚构身份，不是完整登录验收。

仍使用单服务进程的文件存储；外部文件变动检查不是多进程共享事务保证，fsync/rename也不宣称所有硬件断电均可恢复。审计低频但文件会增长；未来归档必须可追溯且另行设计，不可静默截断。完整 server 与 Admin 页面尚未接入，后续必须替换旧配置双写路径，使用本存储对象作为唯一参数权威并从旧操作日志入口读取新审计；组件通过不代表封装完成。
