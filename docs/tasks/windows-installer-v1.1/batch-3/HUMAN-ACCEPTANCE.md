# Win10 人工验收（只有最终 Artifact 自动化通过后执行）

当前文档是待执行步骤，不是已通过记录。使用本轮原始 Actions Artifact，
由主控先核验下载身份和 SHA256，再提供 EXE；不使用本地重新编译包。
不要在包含真实业务资料的实例上测试卸载。已有2B合成测试实例可以继续用。
如果旧Beta正在运行，先保存并在它的窗口选择“停止服务”。

1. 从本轮 Actions 下载原始 Setup Artifact，解压后找到 K-SESSION-Setup-1.1.0-beta.1.exe。
2. 双击 Setup。若安全策略拦截，记录提示并停止反馈；不要关闭 Defender/SmartScreen 或绕过公司安全策略。
3. 完成安装：应不要求管理员密码、Node/npm/Python/Git、命令行、选端口或数据目录。安装默认在当前用户目录。
4. 双击桌面的 K⁺-SESSION；确认开始菜单也有该入口。
5. 确认浏览器自动打开本地页面，启动过程无 CMD 黑框。
6. 新实例在原页面创建测试 Admin；已有2B实例直接用原测试账号登录。确认页面和测试数据正常，不要把密码发到聊天。
7. 保存操作，在 K⁺-SESSION 窗口停止服务；网页应不再可访问。仅关闭浏览器不算停止。
8. 在 Windows“设置→应用”找到 K⁺-SESSION Beta，执行卸载；不要选择或删除其他程序。
9. 确认桌面/开始菜单入口已移除。文件资源管理器地址栏可粘贴
   %LOCALAPPDATA%\K-SESSION\Beta\instance 确认文件夹保留；不要删除或打开后外发 data.json。
10. 再次双击同一个 Setup 安装，再从桌面启动；确认原测试 Admin 和原测试数据仍可使用，不要求重新创建。

请反馈1—10是否全部正常；如有问题，提供步骤号和可见提示（隐藏账号、密码及个人目录信息）。
记录 Windows 版本、Build、x64 和是否出现 UAC；测试机有开发环境不等于干净机认证。
