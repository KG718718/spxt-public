Batch 1C未实现Launcher。复用1B分层设计，由**外置测试harness**通过包内node.exe绝对路径启动app/server.js，并明确cwd；不得调用系统Node。真实浏览器由测试人员打开已确认就绪的回环地址。这仅是G1测试入口，不是最终用户安装流程，也不提前写Launcher/Setup。

利用现有接口将KSESSION_DATA_FILE、CONFIG_FILE、ATTACHMENTS_DIR、BACKUPS_DIR、MAIL_CONFIG_FILE、MAIL_LOG_FILE、SMTP_SECRET_FILE等带KSESSION_前缀的完整变量显式指向包外；OCR解释器指向测试实例中不存在的路径，OCR脚本使用原包路径。邮件启用/正式发送关闭、dry-run，跳过非必要启动任务。控制NODE_OPTIONS/NODE_PATH及npm变量，不从测试工具继承依赖路径；临时目录也在E盘实例外置测试目录。

启动后确认进程可执行路径、PID、回环绑定、HTTP ready；不因日志出现ready就算页面成功。记录实际加载模块路径，确认第三方库来自包内、系统库来自Windows目录。缺DLL即失败，不临时安装组件或放开联网补齐。
